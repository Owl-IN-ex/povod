# Повод собраться

Небольшой планировщик бюджета для дня рождения, вечеринки или любой другой встречи, где хочется заранее понять, сколько всё это будет стоить и кто что приносит.

Проект живёт в одном `index.html`: можно открыть локально или опубликовать через GitHub Pages.

## Что умеет

- считать общий бюджет и окупаемость;
- вести список гостей и подарков;
- учитывать общие и индивидуальные покупки;
- собирать отдельный список покупок;
- распределять расходы между гостями;
- сохранять и переносить данные через Excel;
- работать в светлой и тёмной теме.

## Зачем вообще это сделал

Потому что обычная таблица быстро превращается в кашу: кто идёт, кто сколько дарит, сколько мяса покупать, что уже куплено и почему бюджет опять не сходится.

Здесь всё это собрано в одном месте и пересчитывается автоматически.

## Статус

Проект пока развивается. Интерфейс, логика расчётов и мобильная версия периодически меняются по мере использования.

Если найдёшь странное поведение или есть идея, что добавить — можно написать через форму обратной связи внутри приложения.
